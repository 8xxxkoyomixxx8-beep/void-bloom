VOID BLOOM is an original twin-stick arena survival game that plays offline in a desktop browser from the static files under `game/`. You are the Warden, last light of a garden at the end of the world: survive 10 escalating waves of five kinds of blight, pick one of three stackable gifts each time you level, and cleanse the Heartbloom boss on waves 5 and 10. Clear wave 10 to win; if your HP reaches zero the run ends. Hand-rolled canvas 2D and synthesized WebAudio sound and music — no assets, no libraries, no network requests. Controls: WASD or arrows move, mouse aims, click or Space fires, Shift dashes (with i-frames), P or Esc pauses, M mutes, R restarts.

## Run it

```sh
node serve.ts
# serves game/ locally; open the printed localhost address in a browser
```

`node main.ts` builds the entry's output (the game, its screenshots and dossier.json) into the output directory instead.
